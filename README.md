# **🛒 SQL Retail Analytics Project**

## 📌 Overview

SQL Retail Analytics Project is a data analysis project built using **Oracle SQL** to analyze retail sales data and generate business insights.

The project includes database creation, data insertion, data cleaning, analysis, and advanced SQL queries using real-world retail scenarios.


## 🎯 Objectives

- Analyze retail sales performance
- Understand customer purchasing behavior
- Calculate important business KPIs
- Identify top-performing stores and categories
- Perform customer segmentation
- Apply advanced SQL techniques
